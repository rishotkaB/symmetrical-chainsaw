# Алиса + ChatGPT через Vercel

Навык Яндекс Диалогов → вебхук на Vercel → OpenAI API → голосовой ответ на Станции.

## Деплой

1. Положите папку в git-репозиторий и импортируйте его в Vercel
   (или `npm i -g vercel && vercel --prod` из папки проекта).
2. В Vercel → Settings → Environment Variables добавьте:
   - `OPENAI_API_KEY` — ключ OpenAI
   - `ALICE_SECRET` — любая длинная случайная строка (защита от чужих запросов)
   - `OPENAI_MODEL` — необязательно, по умолчанию `gpt-4o-mini`
3. Передеплойте проект, чтобы переменные подхватились.
4. Проверка с компьютера:

   ```
   curl -X POST "https://ВАШ-ПРОЕКТ.vercel.app/api/alice?key=ВАШ_СЕКРЕТ" \
     -H "Content-Type: application/json" \
     -d '{"version":"1.0","session":{"new":true},"request":{"command":"","original_utterance":""}}'
   ```

   В ответ должно прийти приветствие.

## Навык в Яндекс Диалогах

1. Откройте dialogs.yandex.ru/developer, создайте диалог типа «Навык в Алисе».
2. Webhook URL: `https://ВАШ-ПРОЕКТ.vercel.app/api/alice?key=ВАШ_СЕКРЕТ`
3. Имя активации — например «умный помощник» (нельзя использовать слова вроде «чат» и «GPT» в некоторых вариантах, при отказе модерации поменяйте).
4. Не публикуйте навык: в режиме черновика он работает на устройствах,
   привязанных к вашему аккаунту Яндекса. Тестируйте во вкладке «Тестирование».
5. На Станции: «Алиса, запусти навык умный помощник».

## Ограничения, о которых стоит знать

- Алиса ждёт ответ вебхука 3 секунды. Поэтому в коде таймаут запроса к OpenAI 2,3 с,
  короткие ответы (до 200 токенов) и быстрая модель. Если GPT не успел, Алиса
  попросит повторить вопрос.
- Холодный старт функции Vercel может съесть часть этого времени. Первый запрос
  после простоя иногда будет неудачным, это нормально.
- Навык не заменяет Алису целиком: он запускается фразой активации и работает,
  пока вы не скажете «хватит».
- Оплата OpenAI API с российских карт обычно не проходит, нужен сторонний способ
  пополнения. Сам вызов API с серверов Vercel (регион fra1) региональных блокировок не имеет.

## Что можно улучшить дальше

- Стриминг не поможет (Алиса ждёт целый ответ), но можно добавить кнопки и быстрые ответы.
- Подмешать к промпту ваши данные: умный дом, календарь, заметки.
- Сохранять историю в Vercel KV/Upstash, если нужна память между сессиями.
